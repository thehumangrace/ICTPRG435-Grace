# Project Brief

This project was completed as a scripting exercise for a cyber security course. The brief was framed as a workplace scenario: I was a network engineer who received a request from a supervisor character, J. Brin, asking me to build and document a Python application, then correct three broken scripts and record how I debugged them.

My reply to that email, identifying the tools I used, opens the [full report](https://claude.ai/chat/full_report.md#project-task-1). From there the brief asked for four things: a fully documented application (input, process, output chart, pseudocode, variable list, working code, and a desk check), the corrected versions of three broken scripts, and a step by step debugging record for one of them.

The application itself was a risk calculator. The brief asked for a tool built around two formulae used to price cyber risk in dollar terms: Single Loss Expectancy (exposure value × asset value) and Annualised Loss Expectancy (SLE × annualised rate of occurrence). The desk check data, and the corrected scripts, are documented in the full report.
